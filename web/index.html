Pipeline

Five steps, fully automated

Upload a document and the pipeline handles everything. You only step in to approve.

1

Ingest via API or Dashboard

Upload a single file or batch of up to 20 files via the REST API or drag-and-drop dashboard. The gateway assigns a UUID job ID and queues it in Redis.

POST /api/v1/ingest
2

CPU Triage (Lego 2)

The Celery worker sends the file to the CPU triage service. Digital PDFs, DOCX, XLSX, and CSV files are extracted immediately on CPU without any API call.

Fast-track or forward to VLM
3

Qwen 3.6 27B Vision Extraction (Lego 3)

Scanned PDFs and images are preprocessed (deskew, glare suppression) then processed by Qwen 3.6 27B Vision model. Output is grammar-locked to valid JSON.

~1–3s per page
4

Human Review (Lego 4)

Extracted data lands in the review queue. A reviewer approves, edits, or rejects the record. Approved records are committed to the final database.

Dashboard + keyboard shortcuts
5

Analytics & Export

Committed records are queryable via full-text search. Export to JSON, CSV, or Excel. Live analytics show pipeline health and throughput trends.

Search · Export · Dashboard
